## About

A supervised-learning project that predicts a student's final marks (out of 100) from
three inputs: **study hours**, **attendance %** and **previous marks**. Two regression
models are trained and compared: **Linear Regression** and **Random Forest Regression**.

> The dataset is **synthetic** (500 records generated with seed 42). Results show the
> ML workflow, not accuracy on real student data.

## Dataset

| Column | Range | Role |
|---|---|---|
| Study_Hours | 1 to 10 | Input |
| Attendance | 40 to 100 % | Input |
| Previous_Marks | 30 to 100 | Input |
| Final_Marks | 0 to 100 | Target |

Generated as `Final = 2.5*Study + 0.25*Attendance + 0.45*Previous + noise (sigma = 5)`,
clipped to 0-100. No missing values.

## How to run

```bash
git clone <your-repo-url>
cd <repo-folder>
python -m venv venv
# Windows: venv\Scripts\activate     Linux/macOS: source venv/bin/activate
pip install -r requirements.txt

```

The script regenerates `dataset/student_performance.csv`, saves the graphs to `outputs/`
and prints the evaluation metrics. A fixed `random_state = 42` gives identical results
every run.

## Results (100 held-out test records, 80:20 split)

| Model | MAE | MSE | RMSE | R² |
|---|---|---|---|---|
| Linear Regression | 4.02 | 28.45 | 5.33 | 0.826 |
| Random Forest Regression | 4.59 | 35.13 | 5.93 | 0.786 |

Linear Regression is selected (lowest MAE) because the data was built from a linear
formula. Sample prediction: 6 study hours, 85% attendance, 75 previous marks
-> **70.54 / 100 (Good)**.
